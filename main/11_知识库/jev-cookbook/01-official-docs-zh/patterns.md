# 模式

> 用 TypeSafe 构建系统的架构模式。

TypeSafe 的设计定位是嵌入更大的系统中，用 AI 驱动决策。学会以离散、原子的决策来思考——它们组合成复杂的系统行为——是充分发挥 TypeSafe 效能的一项关键技能。

本节假设你已了解 [TypeSafe 原语](/primitives)并理解[置信度的工作原理](/confidence)。如果还没有，请先阅读这两部分。

## 这些模式

| 模式                                                     | 它做什么                                                                                                   | 收益                     |
| -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------ |
| [推测性扇出](/patterns/fan-out)                          | 在单次调用中发送多个问题，包括推测性的问题，并让你的代码决定哪些是相关的                                   | 成本、速度               |
| [置信度门控路由](/patterns/confidence-routing)           | 把置信度用作第二个决策轴，构建更安全的系统                                                                 | 可靠性、安全性           |
| [复合评分](/patterns/composite-scoring)                  | 把多个分析维度合并为单一评分                                                                               | 成本、可靠性、速度       |
| [意图路由](/patterns/intent-routing)                     | 对用户意图进行分类并路由到相应的处理器                                                                     | 成本、速度               |
