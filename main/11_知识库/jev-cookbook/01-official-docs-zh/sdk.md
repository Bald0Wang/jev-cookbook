# 客户端 SDK

> 安装 TypeSafe 客户端 SDK，在你的应用中使用类型化的问题与答案。

我们的客户端 SDK 为 TypeSafe API 提供类型化的问题与答案，并使用各自的默认重试策略自动处理重试。

选择一个客户端 SDK，查看安装说明、示例和 API 细节。

<Card title="Python" href="/sdk/python">
  安装 Python 客户端 SDK，发起你的第一个请求。
</Card>

<Card title="JavaScript / TypeScript" href="/sdk/javascript">
  安装 JavaScript 客户端 SDK，发起你的第一个类型化请求。
</Card>

你也可以从任何语言直接调用 [HTTP API](/api)。
