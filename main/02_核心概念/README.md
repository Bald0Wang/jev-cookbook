# 第二章 · 核心概念（5 册）

> 第一章带你看了一次"判断长什么样"，本章把五块地基逐个挖开：调用机制、输入格式、问题类型、概率可信度、怎么组装成系统。每一册对应官方文档的一节，全部可运行。

## 01 System One：把生成循环全砍掉

聊天模型回答问题，本质是反复循环：读完上下文→在词表里算一遍→挑一个词拼上→拿着新文本从头再算。生成一段回答，整套网络要硬跑几十上百遍。System One 把这个循环**全部砍掉**：文本只编码一次，底下挂的多个问题在同一次前向里并发求值，在预设选项间算好归一化概率直接返回。

这就是为什么"加问题几乎不改变响应时间"——输入只编码一次，问题在底下并联。第二章第一册用"问题 ID 对照实验"验证这一点：换 ID、换顺序，答案分布不动摇。

## 03 校准：1950 年的数学，2026 年的模型

"给 0.8 概率的事件，长期频率应接近 80%"——这套给概率打分的数学 1950 年评天气预报时就有了（Brier 评分），统计学后来确立了**严格适当评分规则**。近两年学术界把它搬进大模型强化学习（如 MIT 的 RLCR），专治模型盲目自信。Jev 训练目标（RLCD）顺着同一思路：**把概率测得准当作最核心的能力**。

第 4 册里你会亲手算 Brier：把概率推向极端未必更好——校准好和单次对，是两件事。

## 04 核心价值

读完本章，你会拿到判断模型的三张"体检报告"：

- **看懂返回**：choice/confidence/probabilities/noul 每个字段是什么、为什么 Noul 没有置信度；
- **写对问题**：原子性纪律 + criteria 措辞对分布的影响（改措辞→看分布变化，是这章最好的练习）；
- **设对阈值**：0.5、0.6、0.7 都只是应用政策，选它们的依据是标注数据不是感觉。
