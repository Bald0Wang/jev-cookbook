# Jev 与编码智能体

> 当你使用编码智能体时，Jev 是什么（以及不是什么）。

如果你是在为编码智能体寻找一个可以接入的模型时发现了 TypeSafe，请从这里开始。Jev **不是** Claude Code、Cursor、opencode、Copilot、Muse Spark、Grok Bot 或类似工具背后那个 LLM 的即插即用替代品。相反，你可以照常使用编码智能体，来编写调用 Jev 作出决策的代码。

## Jev 不是对话或代码补全 LLM

Jev 是一个 [System One 模型](/concepts/system-one)。它不生成文本、不写代码，也不进行对话。它接收一个[状态](/concepts/state)和一组类型化的[问题](/primitives)，并返回你的代码可以直接使用的结构化答案：

* 从选项列表中给出一个 `choice`，并附带每个选项的概率。
* 在你定义的评分标准上给出一个 `score`。
* 对一条真/假陈述给出一个 `noul`（0–1）。

编码智能体依赖的是能够流式输出文本、调用工具并根据自然语言指令编辑文件的 LLM。Jev 这些都不做。没有任何 `model: "jev-latest"` 设置能把你的编码智能体变成由 Jev 驱动的智能体，因为这两个系统解决的是不同的问题。

## 你可能更想要的做法

选择与你原本想做的事情相匹配的那一行：

| 你想做的事…… | 建议做法 |
| ----------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 让你的编码智能体更擅长*编写使用 TypeSafe 的代码* | 安装 [TypeSafe 智能体技能](/agent-skill)。它为 Claude Code、Codex 和其他智能体提供关于 Jev API、[原语](/primitives)与[模式](/patterns)的完整上下文，使它们能为你生成正确的 TypeSafe 集成。 |
| 在你正在构建的应用或智能体内部使用 Jev —— 用于路由、分类、打分、防护栏或任何结构化决策 | 从[快速开始](/introduction/quickstart)入手，然后阅读[如何用 TypeSafe 构建](/concepts/how-to-build-with-system-one)与[模式](/patterns)，了解[置信度路由](/patterns/confidence-routing)、[意图路由](/patterns/intent-routing)等常见架构。 |
| 替换或更换驱动编码智能体的模型 | Jev 不适用于这个场景。请继续使用基于 LLM 的编码智能体，并在你的产品需要快速、经过校准的结构化决策之处单独使用 Jev。 |
| 在写任何代码之前先试试 Jev | 打开 [Playground](https://console.typesafe.ai/playground)，粘贴一段文本作为状态，并添加几个问题。具体演示请参见[快速开始](/introduction/quickstart)。 |

## 什么时候值得选择 Jev

尽管 Jev 不是编码智能体所用的 LLM，但在你用编码智能体构建的智能体或应用的*内部*，它往往正是合适的工具。当你的代码需要以下能力时，就选择 Jev：

* 把请求路由到一组固定目的地中的一个，并且知道这次路由的置信度有多高。
* 按某个评分标准（紧急程度、质量、风险）给对象打分，并依据这个数值进行分支。
* 在采取行动之前，检查某条陈述对某个文档、消息或记录是否成立。
* 把那种让 LLM“返回 JSON”的脆弱提示词，替换为在构造上就返回类型化值的调用。

如果其中任何一点符合你正在构建的东西，最快的上手路径是[快速开始](/introduction/quickstart)，然后是关于问题类型的[原语](/primitives)参考。
