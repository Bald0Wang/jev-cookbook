# Jev Games Lab

这是两个小游戏的决策复盘页面：

- `Gridloop · 贪吃蛇`：展示轨迹记忆、循环检测、安全路线和置信度约束。
- `Minesweeper · 扫雷`：展示确定雷、确定安全格、子集约束和候选风险概率。

先看 [贪吃蛇双屏同步实验](snake.html)：左侧是原始 Jev，右侧是加入轨迹、候选动作和反馈后的 Jev，两个棋盘共享同一个播放时间轴。

扫雷也有对应的 [双屏同步实验](minesweeper.html)，对比“直接从未知格里猜”和“先处理确定雷、再看风险”。

扫雷双屏使用同一份固定雷盘和同一个程序起手格；两边只改变传给 Jev 的信息和候选动作。

复盘页使用固定轨迹，用于稳定展示；双屏蛇实验右侧默认读取一次真实 Jev 运行保存的 `traces/snake-live.js`，左侧保留原始策略对照；真实游戏入口仍保留实时页面。扫雷的真实运行记录保存在 `traces/minesweeper-live.js`，供后续复盘页面使用。

直接用浏览器打开 `index.html` 即可预览，也可以用任意静态服务器托管该目录。
